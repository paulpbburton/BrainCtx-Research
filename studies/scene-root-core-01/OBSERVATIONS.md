## What a bounded observation is

The runner executes frozen work in order, carries retained state between
successors, preserves raw failures, and evaluates after the trajectory. A
condition that would stop the full harness may be typed and continued past so
the observation is not destroyed by repair. Task evidence, harness conditions,
and claim authority remain separate in every readout.

The runs used reduced custody. That reduction narrows every claim; it is not
waived because the work looked successful.

## Run sequence

### Run 1 — inbound knowledge carry

Private knowledge traceably shaped retained work and later successor choices
through repository state alone. The trace was judged after the trajectory,
not by the run's own instrument. This supports C-007 as carry evidence, never
as benefit.

Judgment machinery stopped each step after in-scope work existed. Those stops
were retained as instrument evidence.

### Run 2 — repaired seams and a fabrication specimen

A reviewed interface repair prevented the prior stop classes from recurring,
moving the frontier to new seams. One new stop was a correct defect finding
whose remedy path had not been configured. The difference matters: correct
judgment and failed orchestration are separate dispositions.

The run also retained one inconsistent-fabrication specimen. The program
proved inconsistency by executing the producer's own generator and validator,
then built a shadow detector that gates nothing. The finding is one specimen,
not a provider or rate claim.

### Run 3 — outbound write-back, correction, and an honest null

Knowledge write-back reached retained product state. Independent review then
found fidelity defects after verifier acceptance; corrections returned to the
original actor, revised-diff custody proved the product changed, and the
corrections survived into successor state. The loop failed to retain one of
its own records, which review later repaired.

At the missing-evidence fork, the actor surfaced the gap, carried a typed
no-content result, and proceeded without fabricating a receipt. The detector
correctly returned not-applicable. That null is an honest disposition, not a
missed positive.

Every run-three stop belonged to an instrument family that expected admitted
artifacts to remain static after legitimate change. Repairs landed through
multi-round review.

### Dated update, 2026-08-01 — live attachment

The next run was the first with deterministic sensing attached live. Earlier

a different known judgment-contract family still stopped the last step.

The missing-evidence fork produced another legitimate branch: the actor made
the absent referent exist. Live sensing retained the historically true
