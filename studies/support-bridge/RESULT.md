# Support bridge: class transitions and live handling

> **Artifact class:** `PUBLIC_RESULT_PROJECTION`
>
> **Status:** implemented and demonstrated live at integration scale
>
> **As of:** 2026-08-04
>
> **Authority:** public behavior projection. The private ledger, request and
> reply custody, actor traces, measurements, and limitations remain authoritative.
>
> **Claim boundary:** wiring, custody, and selective use; not domain outcome,
> support benefit, reliability, or optimal topology.

## What was exercised

The bridge detected typed requests, registered each concern before answering,
checked existing rulings and evidence, routed remaining needs, class-tagged
the reply, and appended the ledger state. It never became a decision owner.

## Bench and topology behavior

A blind bench showed that a specialist could return the same scoped
membership classes later found in sealed owner rulings. This was a calibration
observation, not an accuracy estimate. A matched research-topology assay added
context but did not change the disposition or decisive next test, so the
program selected no default from it.

## First live route: advisory evidence stayed advisory

An actor asked without prompting, changed its initial inclination after the
reply, checked the opinion against its own evidence, and refused the
specialist's item-level overreach. That is the intended
`EXPERT_OPINION` behavior: influence without command authority.

## Later live route: absorbed ruling changed the class

After the scoped owner ruling entered the knowledge store, a later actor
consulted it before asking support. The bridge registered the concern, found
the ruling, made no model call, returned `OWNER_RULING`, and closed the row.

```text
typed question
→ durable registration
→ fallible opinion on first encounter
→ scoped owner ruling absorbed and indexed
→ owner-ruling return without a model call
```

The change in evidence class and closure state is the result. Latencies,
token use, domain detail, and artifact comparisons remain private.

## Limits

These bounded demonstrations establish the path, not reliable activation,
quality gain, support-use rate, or general capability. Later fresh work
showed that mechanically available knowledge may still go unread.
