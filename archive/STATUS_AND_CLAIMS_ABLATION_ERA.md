## Status vocabulary

| Status | Meaning |
|---|---|
| `DEMONSTRATED_LIVE` | A retained live run exercised the mechanism. |
| `OBSERVED_IN_CURRENT_POPULATION` | Repeated or material observation in the named population; not yet generalized. |
| `IMPLEMENTED_NOT_YET_DEMONSTRATED_LIVE` | Code or tests exist, but the required live composition has not occurred. |
