# Finding — lessons become checks

> **Authority note:** The private record is authoritative; this repository is the legible surface.
> **Status:** demonstrated practice · **As of:** 2026-08-26 · Force and
> ceilings: [../STATUS_AND_CLAIMS.md](../STATUS_AND_CLAIMS.md) governs.

The operator's ruling, verbatim: *"Lessons learned like this deserve
deterministic patterns that get checked and nudged."* The program's
enactment: **a lesson that stays prose is the defect.** Each paid-for
lesson is entered as a row carrying the measured specimens that cost it
and the deterministic predicate that now checks it on the instrument's own
cadence — and a second table lists lessons still awaiting predicates, so a
checked lesson is distinguishable from a merely remembered one.
(Anchor: `LESSON-01`)

Representative rows, described by shape:

- **Enabled is not running.** A service unit crash-looped thousands of
  times while its state read healthy; the predicate now reads restart
  counts and active-while-enabled per heartbeat.
- **A heartbeat is not effect.** The hub once beat every few seconds
  through an eleven-hour wedge its own files described; staleness is now
  keyed with the gate's typed decline reason retained.
- **A recorder records its own outage.** A gap only an operator could
  record was missed; services now emit their own silence as a typed row.
- **Narration is not the act.** A byte-identical retry paused twice
  because only its description field changed; act fingerprints strip
  narration keys.
- **The inventory is read before an absence claim.** A finding was
  re-derived that retained research had already answered; a pre-action
  entry now fires on searching a store root before reading the source
  inventory.
- **A named pattern is armed and its fires counted** — the ruling that
  created the [arm-and-observe flywheel](ARM_AND_OBSERVE.md).

The instrument's own defects enter the same registry: the branch-switch-
over-a-live-suite lesson recurred forty-two minutes after being recorded
as prose — the recurrence itself is the demonstration that prose does not
activate, and the row now owes its predicate. (Anchors: `LESSON-01`,
`NULL-02`)
